# Varun Petekar — Portfolio

My personal portfolio site, live at **https://varunpetekar.github.io/**.

I'm a Data Engineer working on BigQuery data platforms, ETL pipelines and Power BI reporting for US clients. The site covers my experience, projects, skills and certifications. My resume is available as a [PDF](https://varunpetekar.github.io/Varun_Petekar.pdf).

## Built with

- Plain HTML, CSS and JavaScript, with no framework and no build step
- A custom cursor, scroll-reveal animations, animated counters and a parallax hero
- Hosted on GitHub Pages from the `master` branch

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The whole page |
| `styles.css` | Styles, including the mobile layout |
| `script.js` | Cursor, reveal animations, counters, smooth scroll |
| `Varun_Petekar.pdf` / `.docx` | Resume |

## Run locally

Open `index.html` in a browser.
